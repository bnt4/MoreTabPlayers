# More Tab Players
This simple [FabricMC](https://fabricmc.net) mod allows you to customize the number of players in the tab list and bypass the 80-player vanilla restriction.

**The full project description and versions on Modrinth: https://modrinth.com/project/ZAsmrKlj**

## Installation
1. Download the latest release and all required dependencies from [Modrinth](https://modrinth.com/project/ZAsmrKlj).
2. Place the `.jar` files into your `.minecraft/mods` folder.
3. Restart your client.

### Configuration
You can configure the mod in the Mod Menu settings or by editing the `moretabplayers.json` file in your config folder.
